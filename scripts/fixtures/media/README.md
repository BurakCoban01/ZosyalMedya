# Local social media fixtures

These small assets are original, repository-safe local product fixtures. They are
uploaded through the real Media API by `scripts/seed-demo-media.ps1`; UI code
does not import or hardcode them.

- `emre-avatar.jpg`, `ayse-avatar.jpg`, `mehmet-avatar.jpg`,
  `zeynep-avatar.jpg`, `can-avatar.jpg`, `elif-avatar.jpg`,
  `burak-avatar.jpg`, `deniz-avatar.jpg` and `merve-avatar.jpg`: fictional
  profile portraits generated with the built-in Codex image generation tool.
- `istanbul-workspace.jpg`: original editorial workspace scene generated for
  profile covers, posts and message attachments.
- `data-studio.jpg`: original collaborative data-workshop scene generated for
  profile covers, posts and quote attachments.
- `izmir-workspace.jpg`, `writer-cafe.jpg` and `research-library.jpg`: original
  editorial scenes generated for distinct profile covers, posts and Stories.
- `data-studio-motion.mp4`: a three-second silent H.264 fixture derived from
  `data-studio.jpg` with FFmpeg 8.1.2. It is intentionally small and contains
  no third-party audio.

All prompts required fictional subjects or unbranded scenes, with no readable
text, logos, watermarks, public figures or copyrighted interfaces.
